# Open Assistant brand

The mark is **Handoff**: two pointers meeting tip to tip. The black one is the user and the orange one is the agent, sharing one cloud PC. It stands for "watch or take control".

## Colors

| Token | Light surfaces | Dark surfaces |
|---|---|---|
| Ink (user pointer, wordmark) | `#151515` | `#F2F2EF` |
| Signal (agent pointer) | `#FF4D1A` | `#FF5C2E` |
| Background | `#F2F1EC` | `#121215` |

Signal orange is the primary brand color. In the UI it is the main accent (primary buttons, links, focus, selection) and it also marks agent activity (running tasks, the agent's cursor in the VM stream), so the logo and the product speak the same language. Ink and background stay neutral so the orange stands out.

## Type

Wordmark: Schibsted Grotesk Bold, lowercase, tracking -2%, outlined to paths (no font needed to render the SVGs). Licensed under OFL.

## Files

| File | Use |

| `mark.svg` / `mark-on-dark.svg` | Symbol alone, on light / dark backgrounds |

| `favicon.svg`, `favicon.ico` | Web and Tauri window icons |
| `png/` | Raster exports: app icon 1024/512/192, `apple-touch-icon.png` (180), favicons 16/32/48, lockups |

## Regenerating

Every file here is generated by `build.py`. To change the mark, colors or wordmark, edit the values at the top of the script and run it:

```bash
python3 assets/brand/build.py
```

Requires Python 3 with `fonttools`, `rsvg-convert` (librsvg) and ImageMagick. The font is downloaded on first run into `.cache/` (git-ignored).

## Rules

- Keep the pointers tip to tip, with the user's pointer at the top left and the agent's at the bottom right. Don't rotate, mirror or separate them.
- Clear space around the mark is at least the width of one pointer.
- Don't swap the colors between the two pointers.
